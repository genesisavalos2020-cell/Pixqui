PIXQUI

Sistema inteligente creado para brindar seguridad a los niños, utilizando tecnología con ESP32 para detectar cuando un niño se aleja demasiado de su cuidador.

Dispositivo Niño

Pequeño dispositivo encargado de enviar información sobre la distancia entre el niño y su cuidador.

Dispositivo Cuidador

Recibe la información del sistema y genera una alerta cuando el niño se encuentra fuera del rango establecido.

Tecnología

Utiliza componentes electrónicos y programación para crear una solución práctica y confiable.
